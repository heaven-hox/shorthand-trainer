# shorthand-trainer

方式に依存しない、日本語速記の練習用デスクトップアプリです。音声をヘッドホンで聞いて紙に速記し、紙で反訳したあとに原文を開示します。初級の単語練習を中心に、文章の読み上げにも対応します。PCへの答案入力・自動採点は行いません。

## 導入と起動

Windowsを優先した初版です。Python 3.12、uv、Tkinter/ttk、VOICEVOX ENGINE、sounddeviceを使います。macOS/Linuxも考慮していますが、各OSの実機検証は別途必要です。

1. [uv](https://docs.astral.sh/uv/getting-started/installation/)を導入してください。
2. [VOICEVOX ENGINEの配布ページ](https://github.com/VOICEVOX/voicevox_engine/releases/latest)からOSに合うエンジンを導入し、CPUモードで起動してください。すでにVOICEVOXエディターを使用している場合は、そのエンジンにも接続できます。初版ではエンジンやモデルを同梱・自動ダウンロードしません。
3. このリポジトリを取得し、Windowsでは `start.bat`、macOS/Linuxでは `./start.sh` を実行します。初回はuvがPythonと依存関係を用意するため、ネットワーク接続が必要です。
4. アプリの「接続して声を取得」で声・スタイルを選び、問題を生成してください。

起動スクリプトは自身のディレクトリに移動してから `uv sync --locked --no-dev` と `uv run --frozen --no-sync shorthand-trainer` を実行します。空白・日本語を含むパスにも対応します。依存関係は `uv.lock`、Pythonの系列は `.python-version` で揃えます。エンジン・OSの音声ドライバー・Tkの実行環境はuvの管理外です。

Linuxではディスプレイ、Tk、PortAudioの共有ライブラリが必要になる場合があります。Debian/UbuntuのシステムPythonを使う場合のパッケージ例は `python3-tk libportaudio2` です。GUIを表示できるデスクトップ上で実行してください。

Linuxのuv管理Pythonでは、Tkのビルドによって日本語のベクトルフォントを認識せず、文字が正常に表示されない場合があります。その場合はTk付きのシステムPython 3.12/3.13を使い、例えば `UV_PYTHON=/usr/bin/python3.13 ./start.sh` で起動してください。この実装ではPython 3.12.14/Tk 9と、システムPython 3.13.5/Tk 8.6でテストし、日本語表示は後者で確認しています。

手動起動・確認:

```sh
uv sync --locked
uv run shorthand-trainer
uv run shorthand-trainer --check-voicevox
uv run shorthand-trainer --check-voicevox --engine-url http://127.0.0.1:50021
uv run shorthand-trainer --list-devices
uv run python -m tkinter
```

ローカルのエンジンへの接続はHTTPプロキシを経由しません。通常は `http://127.0.0.1:50021` を使います。接続エラー時はエンジンの起動・URL・ポートを確認してください。音声デバイスを認識しない場合はOS側の出力設定を確認し、「音声出力」を更新してください。

## 出題

### 単語：パターン生成

初回の生成パターンは空欄です。使いたい方式・練習範囲に合わせて入力してください。例えば `[あいうえお]{2}` は、指定した5文字を2文字ずつ組み合わせた25種類です。

- ひらがな、長音符 `ー`、文字クラス `[あかさ]`、範囲 `[あ-お]`、連結、括弧・選択 `(あ|か)`、省略 `?`、有限の回数指定 `{2}` / `{1,3}` に対応します。外側の `^` / `$` は省略可能です。
- `*`、`+`、後方参照、先読み・後読み、否定文字クラス等は対応しません。これは検索用正規表現の全機能を逆向きに実行する機能ではありません。
- 全候補を文字列として列挙せず、有限オートマトンで異なる単語の数を計算して抽選します。`(あ|あ)` など、同じ文字列になる選択肢も重複として統合します。
- 1文字もない生成結果は出題しません。例えば `あ?` の候補は「あ」だけで、文字のない結果は除きます。**「ん」1文字は除外しません。** `ん?` の候補は「ん」だけです。重複なしで候補数を超えた指定は、合成前にエラーにします。
- 入力は256文字、括弧は16段、繰り返しは32回、生成単語は64文字までです。複雑すぎるパターンは状態数の上限でエラーになります。

### 単語：TXT 読込

- 1行1語。行の前後の空白と空行、句読点だけの行を除外します。
- UTF-8（BOM可）またはCP932を、パス欄の下のプルダウンで指定します。文字化けを隠す置換読み込みはしません。
- フィルタはPythonの通常の正規表現検索です。完全一致は `^[ぁ-ん]{2,5}$` のように指定します。空欄は全件対象です。
- 重複なしの場合は同じ単語（文字が完全に一致する行）を1つにまとめ、候補数を超えた指定はエラーになります。
- 順出題・重複ありでは末尾から先頭へ戻ります。シャッフル・重複ありでは復元抽選します。
- `examples/kana_words.txt` を試せます。サンプルは12語なので、重複なしの出題数は12以下にしてください。

外部の単語辞書もこの形式で利用できます。「豚辞書」の紹介は、対象となる配布元と利用条件を確認できてから追加します。辞書は同梱していません。

### 文章：TXT 読込

指定ディレクトリ直下のTXT（拡張子は大文字・小文字を区別しない）から1本を選び、全文を使用します。サブディレクトリは探索しません。選ばれたファイルが空の場合はエラーになります。`examples/articles` を試せます。

乱数シードを指定すると、同じ入力・設定で出題を再現できます。空欄では自動生成し、ログに記録します。TXTの上限は1ファイル8 MiB、単語の出題数は10000個、音声時間の上限は30分です。

## 前回の設定を記憶する

**アプリの通常終了時に入力設定を自動保存し、次回起動時に復元します。** 設定保存ボタンの操作や問題の生成は不要です。生成に使わなかった編集内容も終了時の状態を記憶します。

対象は出題モード、生成パターン、TXTとディレクトリのパス、文字コード、フィルタ、出題順・個数・重複可否、乱数シード欄、エンジンURL、声・スタイルとクレジット、話速、休止設定、記録保存先、音声出力です。乱数シードを空欄で終了すると次回も空欄になり、生成のたびに新しい問題を作れます。

声・スタイルは次回のエンジン接続後に再選択します。エンジンへの自動接続はしません。保存した声や音声出力が見つからない場合は、利用可能な既定の選択に戻ります。

設定ファイルの保存先:

| OS | 保存先 |
| --- | --- |
| Windows | `%APPDATA%\ShorthandTrainer\settings.json` |
| macOS | `~/Library/Application Support/ShorthandTrainer/settings.json` |
| Linux | `$XDG_CONFIG_HOME/shorthand-trainer/settings.json`（未指定なら `~/.config/shorthand-trainer/settings.json`） |

設定は一時ファイルからの置き換えで保存します。読み込めない設定ファイルは通知して初期設定で起動し、そのファイルは上書きしません。初期状態へ戻したい場合は、アプリ終了後に設定ファイルを退避してください。強制終了時には、その回の編集内容が保存されない場合があります。問題文や練習の途中状態は復元せず、練習記録として別に保存します。

## 速度と休止

**VOICEVOXの話速を0.5〜2.0倍の範囲で手動指定します。初期値は1.0倍です。** 単語・文章ともに、指定値をそのままエンジンの `speedScale` に渡します。分速に合わせる自動補正、生成後の時間伸縮、サンプルレートの変更による減速は行いません。

生成後、**文字数・音声の秒数・選択した話速・実測分速（休止除く／休止込み）・休止の合計秒数**を表示します。文字数は空白とUnicodeの句読記号を除く原文の文字数です。小書きの「ゃ」等も1字に数えます。読み仮名への変換やモーラ数への換算はしません。

休止の設定:

- 読点 `、` と句点 `。` の休止を0.1字分刻みで指定します。単語間は句点の設定を使います。最後の単語・文の後には休止を追加しません。改行・`！`・`？` も句点の休止として扱います。
- 「休止の換算基準（字／分）」は、休止を秒に換算するためだけの値です。初期値は60字／分で、VOICEVOXの話速や目標分速を指定する欄ではありません。
- `休止秒数 = 指定した字分 × 60 ÷ 休止の換算基準`。換算基準60なら、0.5字分は0.5秒、2字分は2秒です。話速を変えても、同じ休止設定なら無音の秒数は変わりません。
- 単語は文末の抑揚を付けて合成します。文章も句読点で分割して合成し、エンジン既定の休止を除いて、指定した無音を結合します。長い区間は180文字ごとに分割するため、区切りによって抑揚が変わる場合があります。

換算例:

| 休止の換算基準 | 読点0.5字分 | 句点・単語間2字分 |
| --- | ---: | ---: |
| 60字／分 | 0.50秒 | 2.00秒 |
| 80字／分 | 0.375秒 | 1.50秒 |
| 120字／分 | 0.25秒 | 1.00秒 |

画面には換算後の秒数も表示します。表示は小数第2位までですが、音声には24,000 Hzのサンプル数に丸めた時間を使います。

音声ファイルを作る手順:

1. 単語モードでは単語ごと、文章モードでは句読点・改行ごとに読み上げる区間を分けます。単語内の句読点も同じように区切ります。
2. 各区間をVOICEVOXで合成します。エンジンに指定できる前後の無音を0にし、エンジン側の句読点用休止を外します。子音・母音の長さは変更しません。
3. 各区間の音声の間に、上の式で求めた無音を挿入して、1本のWAVに結合します。

例えば3単語なら `単語1の音声 → 無音 → 単語2の音声 → 無音 → 単語3の音声` です。単語間2秒で各単語の音声が合計6秒なら、完成した音声は `6 + 2 × 2 = 10秒` になります。最後の単語の後には無音を追加しません。

初級の単語練習では、まず話速1.0倍で試し、書く時間が足りなければ「句点・単語間」の休止を長くします。聞き取りづらい場合は話速を0.5〜1.0倍の範囲で調整してください。「同じ問題で音声を再生成」を使うと、問題文・出題順・乱数シードを固定したまま、話速・休止・声を変えて比較できます。元のTXTを読み直さず、出題設定欄の変更も適用しません。再生成ごとに新しい記録を保存し、以前の音声は上書きしません。

実測分速は `文字数 × 60 ÷ 音声の秒数` です。「休止除く」はアプリが挿入した無音だけを除いた値で、合成音声内の自然な短い間は含みます。再生中の一時停止時間は音源自体の分速に含めません。話速と分速の関係は問題文・話者により変わるため、「0.5倍＝60字／分」等の固定プリセットは用意していません。

文章モードは自主練習用で、**日本速記協会の速記技能検定に準拠する疑似検定ではありません**。公式の文字数算定・朗読条件・反訳時間との照合は未実施です。

## 練習と記録

1. 問題・音声を生成します。原文は画面に表示しません。
2. 「再生して練習開始」で紙に速記します。一時停止・再開ができます。
3. 再生完了後、自動で反訳用ストップウォッチが始まります。紙で反訳してください。
4. 「反訳終了・原文を開示」で原文を表示し、反訳時間を記録します。

練習を中断した場合も、その状態を残して原文を開示できます。進行中の練習は、アプリ終了時に中断として記録します。生成処理のキャンセルは進行中のAPI呼び出し終了後に反映されます（各リクエストのタイムアウトは60秒）。

初期保存先は `~/ShorthandTrainer/sessions` です。生成完了時に次のディレクトリを作り、進行に応じてJSONを更新します。

```text
20261028T153045.123456+0900/
  problem.txt
  audio.wav
  credits.txt
  session.json
```

フォルダ名はWindowsで使用できる日時の基本形式です。JSONにはタイムゾーン付き日時、元ファイル、出題設定、実際の乱数シード、文字数基準、声・エンジン・選択した話速、休止換算基準、実測分速、反訳時間、完了／中断、一時停止回数を記録します。問題文はディスクには保存されますが、アプリでは反訳終了まで隠します。

現在の記録は `schema_version: 2`、`audio.speed_mode: "manual"` です。`audio.settings.speed_scale` は手動話速、`pause_cpm` は休止の換算基準です。既存の記録は書き換えません。

## 開発とテスト

```sh
uv sync --locked
uv run pytest -m "not gui"
uv run ruff check .
uv run ruff format --check .
```

GUI統合テストは実際のTkウィンドウを使います。音声合成APIと音声出力にはテスト用実装を使うため、VOICEVOXやスピーカーは不要です。

```sh
# Windowsのデスクトップ等、GUIが使える環境
uv run pytest -m gui --run-gui
# Linuxのヘッドレス環境（Xvfbが必要）
xvfb-run -a uv run pytest --run-gui
```

テストではパターンの一意性・候補上限、文字コード、検索フィルタ、HTTPの要求と応答、手動話速の範囲と透過性、休止、同一問題の音声再生成、キャンセル、再生制御、原文開示とログの一巡を検証します。実際のVOICEVOXの読み品質、物理デバイスでの再生、Windows実機での起動は別途確認が必要です。

実エンジンとの疎通・WAV生成は、公式配布のVOICEVOX ENGINE 0.26.0（Linux CPU版）で確認しています。従来の `talk` と新しい `streaming_talk` の話者を受け付け、通常の `/audio_query` と `/synthesis` を使用します。Windows/macOS向けCIは設定済みですが、CIの実行結果はまだ確認していません。
